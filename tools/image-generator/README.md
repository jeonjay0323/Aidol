# AI 아이돌 이미지 생성기

카드 등급별로 두 개의 생성기가 있다. 얼굴 품질 규칙·랜덤 축·레퍼런스·생성 로직은 `normal.py`에
모여 있고, `epic.py`가 그걸 import해서 프롬프트만 다르게 조립한다.

| | normal | epic |
|---|---|---|
| 축 | 동물상 프리셋 5종 | 종족 6종 |
| 의상 | 일상복 (무채색·단색·프린트 금지) | 코스프레 컨셉 의상 |
| 비율 | profile 4:3 / editorial 3:4 | 3:4 고정 |
| 룩 | 담백한 프로필·화보 | Y2K 디지캠 필름룩 |
| 레퍼런스 | face + pose + outfit | pose + cosplay (+face 옵션) |

```
python3 normal.py --mode editorial --gender both
python3 epic.py --gender f --n 2
python3 sheet.py out            # 결과 컨택트시트
python3 prep_refs.py            # 레퍼런스 워터마크 제거 (레퍼런스 추가하면 실행)
```

## 파일

| | |
|---|---|
| `normal.py` | 공용 엔진 + normal 프롬프트. `--help` 참고 |
| `epic.py` | 종족 프롬프트. normal 을 import 해서 재사용 |
| `prep_refs.py` | 레퍼런스 하단 10% 크롭 → `refs_clean/` |
| `sheet.py` | 결과 컨택트시트 HTML 생성 후 브라우저로 열기 |
| `out/` | 최신 결과 |
| `keep/` | 채택된 기준컷 |
| `refs_clean/` | 워터마크 제거된 레퍼런스 사본 (생성기가 실제로 보는 것) |
| `archive/` | 과거 버전별 결과 35개 |

## 레퍼런스 (`~/Desktop/`)

| 폴더 | 담당 | 파일 규칙 |
|---|---|---|
| `face_boy` / `face_girl` | 얼굴상 + 헤어 | `{동물상}_{번호}` — 프리셋별 매칭 |
| `pose_boy` / `pose_girl` | 상체 각도·팔손·고개 | 자유 |
| `outfit_boy` / `outfit_girl` | 의상 (normal 전용) | 자유 |
| `cosplay_girl` | 의상·메이크업·액세서리·분위기·**얼굴** (epic 전용) | `{종족}_{번호}` |

- **레퍼런스가 담당하는 축은 텍스트 지정이 자동 생략된다.** 둘 다 넣으면 서로 상쇄돼 레퍼런스가 무력해진다
- 폴더가 비어 있으면 그 축만 텍스트로 폴백 (현재 **여자 늑대상 얼굴 없음**, **cosplay_boy 없음**)
- macOS 한글 파일명은 NFD라 비교 전에 NFC 정규화한다
- **워터마크는 프롬프트로 못 막는다.** 여섯 번 시도해 전부 실패했고, `prep_refs.py`로 하단을 잘라내는 것만 통했다

### 닮았지만 다른 사람 만들기

추상적인 "다른 사람으로 만들라"는 안 먹힌다. `DEVIATIONS` 16종에서 매번 N개를 뽑아
**레퍼런스 대비 구체적 편차**를 강제한다 (normal 3개 / epic 5개).

```
Compared to the person in the attached reference photos, this person differs as follows:
set the eyes a little further apart; give noticeably fuller lips;
make the face noticeably longer and narrower. These differences are mandatory.
```

같은 레퍼런스에서 매번 다른 얼굴이 나오게 하는 역할도 겸한다.

## 확정된 규칙

**공통** — 실존 인물 금지, 이미지 내 글자·워터마크 금지, 전신 금지(가슴 위 크롭, 머리가 프레임의 35~40%)

**normal** — 모자·조끼·민소매 아우터 금지, 어깨 흘러내림·팔가슴 노출 금지, 옷은 단색(패턴·프린트·글자 금지), 워시드 뉴트럴 팔레트

**epic** — normal 의 일상복 제약을 상속하지 않는다(`EPIC_SUBJECT`/`EPIC_SHARED` 별도).
헤드피스·뿔·귀는 필수, 노출 허용. `COSTUME_RULE`이 "평범한 티셔츠·가디건으로 축소 금지"를 강제

## 프롬프트 조립에서 배운 것

1. **위치가 곧 우선순위** — 뒤에 올수록 강하다. 표정·피부·카메라 규칙을 뒤로 뺀 뒤에야 앞의 지시를 이겼다
2. **한 축은 한 곳에서만** — 헤어를 텍스트와 레퍼런스 양쪽에서 지정하면 서로 상쇄된다
3. **금지만으로는 안 된다** — 레퍼런스에 "무시하라"만 잔뜩 걸면 기여할 자리가 없어져 무력해진다. 역할을 줘야 작동한다
4. **AI 티의 정체는 완벽함** — 비대칭·잔머리·초점 이탈·크루킷한 소품 배치를 명시적으로 요구해야 사진이 된다
5. **헥스코드는 이미지에 글자로 박힌다** — 색은 반드시 서술어로
6. **모드가 결과를 좌우한다** — profile과 editorial은 사실상 다른 사진. "예전 같지 않다"의 원인이 프롬프트가 아니라 모드였던 적이 있다

## 알려진 이슈

1. **의상 레퍼런스가 노출·크롭 규칙을 이긴다** — 무신사 전신 룩북이 크롭 지시를 누르고, 코스프레 오프숄더가 노출 금지를 이긴다
2. **드레싱룸 셀카는 의상이 잘 안 읽힌다** — `mermaid_1` 같은 컷은 코스튬 대신 평상복이 나오기도 한다
3. **`cosplay_boy` 없음** — 남자 epic 은 `--refs face,pose` 로 돌리고 의상은 텍스트 폴백을 쓴다
