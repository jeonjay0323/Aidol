# 버추얼 캐릭터 통화 — 하늘

## 목표

2D 컨셉 설정화로 만든 버추얼 캐릭터와 얼굴을 보며 음성으로 대화한다.
실사 카드(Simli)와 같은 카드 · 통화 · 멀티콜 구조를 그대로 쓰되, 얼굴은 브라우저가 3D 모델로 직접 그린다.

첫 캐릭터는 버추얼 라이버 **하늘(HANEUL_LIVE)** — 하늘색 트윈테일, 토끼 귀 헤드폰, 민트 후드티.

---

## 기능

| 기능 | 내용 |
|------|------|
| 대화 | 1:1 영상통화. 말하면 캐릭터가 목소리로 답하고 입이 움직인다 |
| 커스텀 | 머리 · 눈 · 상의 · 하의 · 신발 색, 말투(반말/존댓말), 나를 부르는 호칭, 한 줄 설정 |
| 다인 콜 | 기존 멀티콜에 그대로 참여. 꾸민 색 · 말투가 함께 반영된다 |

꾸미기를 저장하면 그 모습을 한 장 찍어 카드 사진으로 쓴다(카드 화면 · 로비 · 멀티콜).
인쇄용 카드는 실물과 같아야 하므로 원래 이미지를 유지한다.

---

## 기술 스택

| 역할 | 선택 | 이유 |
|------|------|------|
| 대화 · 음성 | Gemini Live (`gemini-live-2.5-flash-native-audio`, Vertex AI) | 음성을 듣고 음성으로 바로 답한다. 목소리는 Zephyr |
| 캐릭터 모델 | VRM (VRoid Studio로 제작) | 표정 · 입 모양 · 뼈대가 들어 있어 리깅 없이 움직인다 |
| 렌더링 | three.js 0.180 + @pixiv/three-vrm 3.5 | 브라우저에서 VRM을 그린다. 서버 영상 생성이 없다 |
| 입 움직임 | Web Audio `AnalyserNode` 음량 → VRM `aa` 표정 | Simli 없이 바로 통화. 등록 대기 0 |
| 색 커스텀 | Canvas로 텍스처 재채색 | 음영은 남기고 평균색만 목표색으로 바꾼다 |
| 백엔드 | Python FastAPI + WebSocket | 기존 exhibition-card 서버 확장 |
| 저장소 | Firestore (운영) / SQLite (로컬) | 카드 · 꾸미기 · 스냅샷 |
| 배포 | Cloud Run (asia-northeast3) | HTTPS — 폰 마이크 사용에 필요 |
| 프론트엔드 | 바닐라 JS + Jinja 템플릿 | 기존 scan 화면에 꾸미기 화면 추가 |

**Simli는 쓰지 않는다.** Simli는 실사 사진 카드에만 쓰인다.

## 아키텍처

```
브라우저 (scan.html)
  마이크 → RMS로 발화 구간 판단 ──WebSocket──→ FastAPI (/ws/call/{id})
                                                    ↓ 페르소나 + 꾸미기(말투·호칭·설정)
                                                 Gemini Live
                                                    ↓ 24kHz PCM
  스피커 ← AudioContext ←──────────WebSocket────────┘
     └→ AnalyserNode 음량 → vrm-avatar.js → 입('aa') · 깜빡임 · 숨쉬기 · 고개
```

꾸미기

```
꾸미기 화면 ─ 3D 미리보기 (recolor 즉시 반영)
   └ 저장 → POST /api/cards/{id}/custom   색 · 말투 · 호칭 · 설정 → cards.custom
          → POST /api/cards/{id}/thumb    스냅샷 JPEG → thumbs 컬렉션, cards.thumb_v
```

- 색은 서버가 `avatar.colors`로 내려주고, 브라우저가 모델을 불러올 때 칠한다.
- 말투 · 호칭 · 설정은 서버가 페르소나 뒤에 붙인다(`call.persona_of`). 1:1과 멀티콜 공통.
- 스냅샷은 카드 문서와 따로 둔다. 목록 조회마다 이미지가 딸려오지 않게.

## 파일

| 파일 | 역할 |
|------|------|
| `app/static/vrm-avatar.js` | VRM 렌더 · 입 · 깜빡임 · `recolor()` · `snapshot()` |
| `app/templates/scan.html` | 꾸미기 화면(`#s-custom`) |
| `app/call.py` | `persona_of()` · `avatar_of()`에 색 포함 |
| `app/main.py` | `/api/cards/{id}/custom` · `/api/cards/{id}/thumb` · `/thumb/{id}.jpg` |
| `app/db_*.py` | `custom` · `thumb_v` 필드, `set_custom` · `set_thumb` · `get_thumb` |
| `tools/virtual_card.py` | 버추얼 공식 카드 발급 (프리셋 `haneul`) |

## 실행 · 배포

```bash
# 카드 발급 (모델은 app/static/models/{카드ID}.vrm 으로 복사된다)
./.venv/bin/python tools/virtual_card.py haneul 하늘.vrm 썸네일.png

# 배포 (2026-10-06 새 프로젝트로 이전 — 옛 aidol-505503 은 결제가 꺼져 있다)
gcloud run deploy aidol-card --source . --region asia-northeast3 --project project-d4a769de-d13f-4a6a-a22
```

- 주소: https://aidol-card-938904157102.asia-northeast3.run.app
- 하늘 공식 카드: `0XDWTZX1` (새 Firestore 에서 다시 발급)
- 모델 파일(.vrm)은 git에 올리지 않는다. 배포하는 기기의 `app/static/models/`에 있어야 이미지에 포함된다.
- 운영 DB에 버추얼 카드를 발급할 때는 `DB_BACKEND=firestore`를 붙인다.

## 알려진 제약

- **지금 모델은 VRoid 샘플이다.** 하늘 도안으로 만든 VRM이 나오면 교체한다.
- **색 커스텀은 VRoid 재질 이름 기준이다**(Hair · EyeIris · Tops · Bottoms · Shoes). 다른 툴로 만든 모델이나 따로 붙인 액세서리(토끼 헤드폰)는 바뀌지 않는다.
- **입은 음량만 따른다.** 열고 닫을 뿐 아 · 이 · 우 · 에 · 오 모양은 구분하지 않는다.
- **꾸미기에 주인 확인이 없다.** 카드 페이지를 연 사람은 누구나 바꿀 수 있다(전시 환경 전제).
- **운영 서비스와 DB를 공유한다.** 운영 `aidol-card` 로비에도 하늘 카드가 보이지만, 그쪽엔 모델 파일이 없어 음성 통화로 연결된다.
