## 이벤트 데모 - 웹
🗂️`services/exhibition-card`

### **[구현 완료]**
1. **아이돌 제작 및 인쇄** : 현장 제작 및 서비스 연결 QR 코드 포함
2. **더미 카드** : 63×88mm 트레카 규격, QR 14mm, 인쇄 가능
3. **스캔 랜딩 + 통화 플로우** : 1:1 영상통화 / 멀티콜 화면 (목업)

### **[구현 예정]**
- [ ] **통화 엔진 연결** : 카드 ID → 페르소나·얼굴·목소리 주입
- [ ] **멀티콜 다자 립싱크** : Simli 무료 플랜 1연결 제한 해소 필요
- [ ] **카드 얼굴 이미지** : 현재 플레이스홀더
- [ ] **배포용 고정 도메인** : 현재 로컬 IP 의존

### **[결정 사항]**
- 카드는 **공식 카드 + 유저 카드** 두 갈래, 동일 ID 체계로 통일
- 스캔은 **NFC(현장) + QR(반출)** 병기, 앱 설치 없음
- 멀티콜에서 유저 카드는 **아이돌 + 카드 주인**을 함께 초대
- 노래 제작·춤·꾸미기는 범위에서 제외 (현재 스택으로 구현 불가)
